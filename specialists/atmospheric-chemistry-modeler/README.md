# Atmospheric Chemistry Transport Modeling Specialist

Designs reproducible meteorology-chemistry transport, emissions, source-attribution, and nonlinear control-sensitivity studies for air pollution episodes without inventing model performance or policy effects.

## Versions

- `1.0.0` - initial Marketplace release with 3 bundled Skills and 2 Connector references.

The package uses the OpenScience App export/import v1 layout. Connector entries are references only; credentials and executable Connector configuration are not included.
