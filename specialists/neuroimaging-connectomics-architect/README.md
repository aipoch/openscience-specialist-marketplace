# Multimodal Neuroimaging Connectomics Architect

Designs reproducible structural MRI, resting-state fMRI, diffusion MRI, and multimodal connectomics workflows with distortion, motion, exchangeability, and network-inference controls and no clinical diagnosis.

## Versions

- `1.0.0` - initial Marketplace release with 3 bundled Skills and 4 Connector references.

The package uses the OpenScience App export/import v1 layout. Connector entries are references only; credentials and executable Connector configuration are not included.
