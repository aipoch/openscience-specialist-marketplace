# Precision Agriculture Phenotyping and Prescription Design Specialist

Designs radiometrically defensible UAV phenotyping, spatial validation, crop-stress inference, and machinery-ready variable-rate prescription workflows without inventing yield, nitrogen, or irrigation rates.

## Versions

- `1.0.0` - initial Marketplace release with 3 bundled Skills and 2 Connector references.

The package uses the OpenScience App export/import v1 layout. Connector entries are references only; credentials and executable Connector configuration are not included.
