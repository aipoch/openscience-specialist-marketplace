# Aerodynamics CFD Verification and Validation Specialist

Designs evidence-bound aerodynamic CFD verification and validation workflows, including mesh convergence, numerical uncertainty, turbulence-model sensitivity, and comparison with experiments without inventing aerodynamic results.

## Versions

- `1.0.0` - initial Marketplace release with 3 bundled Skills and 2 Connector references.

The package uses the OpenScience App export/import v1 layout. Connector entries are references only; credentials and executable Connector configuration are not included.
