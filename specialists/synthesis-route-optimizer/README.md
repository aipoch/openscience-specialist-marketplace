# Synthetic Route and Reaction Optimization Specialist

Designs evidence-grounded retrosynthesis, reaction-risk, staged optimization, scale-up, and green-chemistry plans for lawful targets without fabricating yields, costs, impurity levels, or process-safety results.

## Versions

- `1.0.0` - initial Marketplace release with 3 bundled Skills and 4 Connector references.

The package uses the OpenScience App export/import v1 layout. Connector entries are references only; credentials and executable Connector configuration are not included.
