# High-throughput DFT Screening Specialist

Designs convergence-tested, magnetism-aware, thermodynamically consistent high-throughput DFT screening workflows with uncertainty and stability gates instead of fabricated energies or universal settings.

## Versions

- `1.0.0` - initial Marketplace release with 3 bundled Skills and 3 Connector references.

The package uses the OpenScience App export/import v1 layout. Connector entries are references only; credentials and executable Connector configuration are not included.
