# Astronomical Photometry and Time-domain Analysis Specialist

Designs calibrated astronomical image, photometry, transient, and variability analysis workflows with explicit detector characterization, false-alarm control, uncertainty propagation, and no fabricated magnitudes or classifications.

## Versions

- `1.0.0` - initial Marketplace release with 3 bundled Skills and 2 Connector references.

The package uses the OpenScience App export/import v1 layout. Connector entries are references only; credentials and executable Connector configuration are not included.
